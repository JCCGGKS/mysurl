# 短链前端页面方案

## 目标

在 `vue/` 下实现一个单页短链创建器，对接当前后端：

- `POST /api/v1/links`
- `GET /:code`

页面用于输入长链、生成短链、复制短链和验证跳转。

## 范围

本次只做：

- 单页创建器
- 长链输入与基础校验
- 调用创建接口
- 展示 `short_url`、`short_code`、`original_url`
- 复制短链
- 打开短链

本次不做：

- 登录
- 自定义短码
- 后台管理
- 统计报表
- 历史记录持久化
- 二维码

## 页面结构

- 顶部说明区：产品名和一句话说明
- 输入区：长链输入框和生成按钮
- 状态区：提交中、成功、失败反馈
- 结果区：展示短链结果并提供复制、打开操作

## 交互规则

- 仅接受 `http://` 或 `https://` 链接
- 提交时发送 JSON：

```json
{
  "long_url": "https://example.com/article/123"
}
```

- 成功后展示：
  - `short_url`
  - `short_code`
  - `original_url`
- 失败时按后端语义提示：
  - `400` 参数错误
  - `500` 服务错误
  - 网络失败

## 接入约束

- 前端复用现有 API，不新增页面专用接口
- 后续若接入 Go 服务首页，需要避免 `/` 和 `/:code` 冲突
- `vue/docs` 只存文档；源码应放在 `vue/` 的实际工程目录中

## 视觉方向

- 简洁专业
- 偏工具页
- 桌面端和移动端可用

## 验收标准

- 可以输入合法长链并成功生成短链
- 可以展示 `short_url`、`short_code`、`original_url`
- 可以复制短链
- 可以打开短链验证跳转
- 非法输入和接口异常有明确提示
